# ✨ Welcome to the Git Clubhouse!

Hi, future Git pro! This tiny project is your chance to make a first contribution and add yourself to the PEC ACM community card.

## 💙 Make your profile yours

Open `index.html` and replace the sample details on the card with your own:

- Your name
- Your SID
- Your branch
- Your college

Keep the page cute, keep your changes kind, and remember to save your file.

## 🧸 Your first Git adventure

Open a terminal in the project folder. Replace `<repository-url>` with the link shared by the workshop organizers.

```bash
git clone <repository-url>
cd <project-folder>
git switch -c add-your-name
```

Edit your profile in `index.html`, then save and share your change:

```bash
git add index.html
git commit -m "Add my profile"
git push -u origin add-your-name
```

Once it’s pushed, open GitHub and create a pull request so your contribution can join the clubhouse. If GitHub says you can’t push to the project, make a fork first, clone your fork, and run the same steps there.

## 🌱 Little reminders

- A branch is your own safe space to work on a change.
- A commit is a saved snapshot of your work.
- A pull request is how you ask to add your change to the project.
- You don’t need React, packages, or setup for this project—just a browser and a text editor.

You’ve got this. One small commit is a lovely place to start. 💙
